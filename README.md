# GLPI – IT Asset & Helpdesk Platform

## Overview

This repository documents a sanitized GLPI deployment used for IT asset management and helpdesk operations.

Topics covered:

- Asset inventory
- Helpdesk ticket lifecycle
- User and group management
- SLA concepts
- Knowledge base
- Software inventory
- License management
- Network equipment inventory
- Authentication concepts
- Backup and maintenance
- Security hardening

> This repository intentionally excludes production credentials, hostnames, domains, IP addresses and personal data.

## Architecture

```text
Users
   |
GLPI Web Interface
   |
Apache / PHP
   |
MariaDB
```

## Main Features

- Incident management
- Service requests
- Asset tracking
- Computer inventory
- Monitor, printer and network inventory
- Software & license tracking
- Change documentation
- Knowledge base
- Reports and dashboards

## Skills Demonstrated

- ITIL-oriented ticket management
- IT asset lifecycle management
- Linux administration
- Apache, PHP and MariaDB
- Backup planning
- Documentation
